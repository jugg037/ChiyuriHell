# Chiyuri Desktop — release notes

## User-visible changes

- Windows 10-inspired Android desktop with Chiyuri black-and-crimson styling and the CP launcher emblem.
- Start menu with searchable installed Android apps and direct app launching.
- Persistent taskbar pins with reordering and recent-app navigation.
- Three customizable workspaces with independent desktop shortcuts.
- Resizable launcher panels for File Explorer and appearance settings.
- Tablet-oriented keyboard shortcuts and Android Back/Escape navigation.
- Wallpaper presets, custom wallpapers, fit/fill/stretch modes and crimson accent choices.
- File manager with Storage Access Framework permissions, search, sorting, breadcrumbs, refresh and common file operations.
- ZIP, RAR and 7Z archive listing and extraction with password support where supported, path-safety checks and resource limits.
- Device dashboard with battery, storage, memory, network and Chiyuri process information.
- Optional Usage Access for recent-app switching and foreground indicators; root access is never required.

## Platform boundaries

Chiyuri Desktop is an Android launcher, not a Windows emulator. Arbitrary external-app windows and independent Android task stacks remain controlled by Android and Samsung firmware. Unsupported archive formats, encryption methods and codecs are documented in the project notices.
